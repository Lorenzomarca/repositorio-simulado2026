# Sol Chuva

Projeto de consulta ao clima com React + Vite, consumindo a API pública Open-Meteo.

## Como executar

1. Instale o Node.js.
2. Abra a pasta do projeto no terminal.
3. Rode `npm install`.
4. Rode `npm run dev`.
5. Abra o endereço local exibido pelo Vite.

## Logo

Substitua `public/logo/solchuva.svg` pela logo oficial, mantendo esse mesmo nome.

## Dados e ícones

- `public/cidades.csv`: cidades usadas nas sugestões e botões rápidos.
- `public/codigos_wmo.csv`: descrição e ícone de cada código de condição do tempo.
- `public/icones/`: arquivos de ícones usados pelo projeto.

## API

Open-Meteo Geocoding e Forecast. Não utiliza servidor, banco de dados ou chave de API.
